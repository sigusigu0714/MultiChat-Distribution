# MultiChat

MultiChat 2.3.1 は、Twitch・KICK・YouTubeのチャット表示と、任意のOBSリモート操作をまとめるiPhone向けアプリです。

## ダウンロード

[最新版の配布ファイル](../../releases/latest)から `MultiChat-2.3.1-Distribution.zip` または `MultiChat.ipa` を取得してください。ZIPにはIPA・使い方・接続設定の書式見本・検査結果が入っています。

IPAは未署名です。AltStore等を使い、利用者自身のアカウントで署名してインストールしてください。iOS 17以降が必要です。一部の翻訳機能はiOS 18以降で利用できます。

## はじめかた

1. アプリをインストールし、初回の「接続セットアップ」を開きます。
2. ご自身が管理するMultiChat対応サーバーのURLを入力します。管理者からJSON形式の接続設定を受け取った場合は、「接続設定ファイルを読み込む」で入力を省略できます。
3. 接続先を確認して「保存してはじめる」を押します。
4. ご自身のTwitch・KICK等のアカウントを連携します。

[使い方](distribution/START-HERE.txt) / [接続設定の書式見本](distribution/connection.example.json)

Twitch送信とOBS操作は任意です。後から「設定」→「接続セットアップ」で追加できます。

## 接続先について

このリポジトリはiPhoneアプリの配布用です。**共用サーバー、バックエンドの実装、ログイン済みアカウント、認証キーは付属しません。** アプリだけで各サービスの統合チャットを受信することはできず、互換性のあるMultiChatサーバーを別途用意する必要があります。

- チャット接続先はHTTPSで公開された対応サーバーを指定してください。
- Twitch送信には、利用者または接続先管理者のTwitch Client IDとHTTPSのOAuth戻り先が必要です。戻り先は `obsremote` コールバックに対応する構成にしてください。Client Secretをアプリへ入力する必要はありません。
- KICK送信には、対応サーバーでのアカウント連携と送信用キーの発行が必要です。
- OBS操作には、対応するWSSリレーとOBS管理トークンが必要です。
- サーバー管理者は、アカウント一覧・変更操作・チャット配信等の認証とアクセス制限を別途設定してください。

## 接続設定ファイル

最低限の例です。`example.com` の値を、その利用者向けの接続先に置き換えてください。

```json
{
  "serverURL": "https://chat.example.com"
}
```

任意の項目として `obsRelayURL`、`twitchClientID`、`twitchRedirectURI` を指定できます。Twitchの2項目は両方を設定してください。認証キー、パスワード、Webhook URL、アカウント一覧をこのファイルへ入れないでください。読み込み後、保存前に接続先を確認できます。

## プライバシー

- 接続先・アカウントは空の状態で開始します。
- 認証情報は端末のKeychainへ保存します。
- 配布用のアプリ識別子と認証情報の保存領域を使用します。
- 配布物には端末バックアップ・プロビジョニングプロファイル・ビルドログを含めません。
- 公開用の新規履歴で管理しています。

ビルド時にIPAの内容、メタデータ、埋め込み接続先、認証情報に似たパターンを検査します。静的検査はあらゆる脆弱性や利用者が設定するサーバーの安全性を保証するものではありません。

## 開発・ビルド

`iOS/MultiChatViewer.xcodeproj` をXcodeで開いてビルドできます。実機へのインストールは自身の署名設定を使用してください。

GitHub Actionsは次を実行します。

- OBSコントローラーの回帰テスト
- 接続設定ファイルの検証テスト
- iPhone向け未署名IPAのビルドと静的検査
- iPhoneシミュレーターでの初回設定・OBS画面のテスト

このリポジトリには運用環境の認証情報を登録しないでください。
